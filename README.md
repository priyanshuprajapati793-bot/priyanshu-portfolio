# Priyanshu Portfolio

A modern Full Stack Portfolio Website built using HTML, CSS, JavaScript, Node.js, Express.js and MongoDB.

## Features

- Responsive Portfolio Website
- Admin Login Authentication
- Contact Form
- MongoDB Database
- Admin Dashboard
- View Messages
- Delete Messages
- JWT Authentication

## Tech Stack

### Frontend
- HTML
- CSS
- JavaScript

### Backend
- Node.js
- Express.js

### Database
- MongoDB

```bash

cd priyanshu-portfolio/backend
```
